# Pantallas - App Salón

Esta carpeta contiene las pantallas principales de la aplicación.

## Pantallas Principales

### HomeScreen
- Dashboard principal
- Vista rápida de citas del día
- Accesos rápidos

### AppointmentsScreen
- Lista de citas
- Calendario
- Crear/editar citas

### ClientsScreen
- Lista de clientes
- Búsqueda y filtros
- Detalles de cliente

### InventoryScreen
- Lista de productos/servicios
- Gestión de stock
- Agregar/editar items

### SettingsScreen
- Configuración del usuario
- Ajustes del negocio
- Sobre la app

## Convenciones

- Un archivo por pantalla
- Nombre en PascalCase terminado en "Screen"
- Usar hooks para lógica de estado
- Separar lógica de UI en componentes cuando sea necesario
